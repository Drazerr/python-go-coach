# python-go-brushup

This repo is where I practice scripting and coding in Python while learning Go alongside it.

For each exercise, I try to solve the same practical problem in both languages. Python gives me a familiar way to work through the problem first, while Go helps me understand how the same idea is approached with a different type system, error-handling model, standard library, and coding style.

Most of the exercises are based around the kinds of problems I run into or care about in infrastructure, DevOps, SRE, and automation work.

## How I use this repo

Each session focuses on one small problem.

I generally work through:

1. the problem and expected behavior
2. a Python implementation
3. a Go implementation
4. tests in both languages
5. differences between the two approaches
6. notes on what I learned or want to revisit

The goal isn't to make every exercise production-ready. It's to improve my coding habits, get more comfortable with Go, and keep my Python fundamentals sharp.
